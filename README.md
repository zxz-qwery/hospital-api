# ⚙️ hospital-api

医院预约挂号系统 Laravel API 服务端。

提供用户端与后台管理端所需 RESTful API 接口。

---

# 🚀 技术栈

- Laravel
- MySQL
- RESTful API
- Eloquent ORM

---

# ✨ 功能模块

- 用户认证
- 医生管理接口
- 科室管理接口
- 排班管理接口
- 预约管理接口
- 公告通知接口
- 文件上传接口

---

# 📦 项目启动

## 安装依赖

```bash
composer install
```

---

## 复制配置文件

```bash
cp .env.example .env
```

---

## 生成 key

```bash
php artisan key:generate
```

---

## 配置数据库

```env
DB_DATABASE=hospital_system
DB_USERNAME=root
DB_PASSWORD=你的密码
```

---

## 启动项目

```bash
php artisan serve
```
